# 🧩 Managing patches

Learn how to add new, manage existing or remove patches.

## ✅ Steps to manage patches

Select one of the patch sources from the list to manage or remove it.

### Adding patches

1. Navigate to the `Patches` area.
2. Tap the edit button.
3. Use the add button to add a new source.
4. Choose one of the available options[^1]:
   - **Enter URL**: Add patches from a remote location.
   - **Select from storage**: Add patches from local storage.

[^1]: The selected file must use the source API JSON format currently supported by Nexora Manager.
